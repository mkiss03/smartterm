# Assets Directory

This directory contains application assets such as icons and images.

## Required Files

- **icon.png** - Application icon (recommended size: 512x512 or 1024x1024)

## Creating an Icon

You can create or add your own application icon:

1. Create a PNG file named `icon.png`
2. Recommended sizes: 512x512px or 1024x1024px
3. Use a transparent background for best results
4. Place it in this directory

## Icon Formats for Different Platforms

When building for production, you may need different icon formats:

- **macOS**: .icns
- **Windows**: .ico
- **Linux**: .png

You can use tools like `electron-icon-builder` to generate all required formats from a single PNG file.
